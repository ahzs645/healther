Manual import, made calm

A small set of tools that
do exactly what you'd expect.

healther doesn't try to be a sync engine. It's a careful manual importer: pick a file, map its columns to Health fields, and either run the import once or save the mapping as a reusable template you can export and share.

Map columns to Health fields

Open your file, see every column it contains, and connect each one to the matching HealthKit field. Skip what you don't need. Set the unit, date format and source — once, then run.

column → Health field all matched
date_utc  →  startDate ISO 8601
avg_hr  →  HKHeartRate count/min
step_count  →  HKStepCount count
weight_kg  →  HKBodyMass kg

One-time or reusable

Run a mapping once for a one-off file, or save it as a template so the next monthly export goes through in two clicks.

Export & share templates

Saved templates are plain files. Export one, send it to a friend, import it back — your mappings stay yours, and portable.

On-device, always

No accounts, no telemetry, no cloud. Files are parsed, mapped and written entirely on your device — open-source so you can verify.

Honest about scope

healther is a manual importer, not a background sync. You stay in control of what gets written and when — every batch is undoable.
