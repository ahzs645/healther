Local-first by design

Your data never leaves
your device.

healther runs entirely offline. No accounts. No background sync. No analytics SDK. We can't see your data because there's nowhere for it to go — and the source is on GitHub if you'd like to verify.

0 servers, accounts, cookies
100% on-device, every record
MIT open-source license
HealthKit native writes only

No network requests

The app's only outbound connection is for app-store update checks. Verify with Little Snitch.

HealthKit-native writes

healther writes through Apple's audited HealthKit APIs. Records are tagged with their source app and timestamp.

Reproducible builds

The shipped binary matches the GitHub source byte-for-byte. Build it yourself if you'd rather.

Easy to leave

Every import is reversible. One click removes the records healther wrote — your previous Health data stays untouched.
