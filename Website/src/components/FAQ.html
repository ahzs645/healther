Questions, answered

Frequently asked.

Is healther really free? +

Yes — free as in beer and free as in speech. The app is open source and MIT-licensed. There's no paid tier, no upsell, no telemetry. If you find it useful, a star on GitHub means the world.

Does any of my data leave my device? +

No. healther parses, previews, and writes everything locally. The app is designed without accounts, telemetry, or a sync backend. The source is on GitHub if you'd like to read it.

Which devices & apps are supported? +

We ship a handful of starter templates and the rest is community. Anything that exports CSV, JSON or TSV will work — you build the column mapping once, save it as a template, and reuse forever.

What if my import is wrong? +

healther tags every record with a unique import-batch ID. One click undoes the entire batch. Your existing Health data is never touched — we only ever add the records we wrote, and we only ever remove our own.

Does it work on iPhone, or just Mac? +

Both. The iOS app writes directly to Apple Health on your phone. The macOS app uses iCloud's HealthKit sync, so records show up in Health on your phone within a few minutes.

How can I help? +

Add a template for a device we don't support yet, file a bug, or translate the UI. Pull requests are reviewed within a few days. The README has a contributor guide.
