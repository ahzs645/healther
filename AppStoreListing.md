## Description

Healther helps you import health data from CSV and JSON files into Apple Health.

Use built-in templates for common health exports, or create a manual mapping for your own file. Pick the date field, map columns or JSON keys to Health fields, preview the generated records, then choose whether to save them to Apple Health.

What you can do:

- Import CSV and JSON health exports.
- Use built-in templates for supported sources.
- Create one-time manual imports.
- Save reusable import templates.
- Export and share template files.
- Preview records before writing anything to Apple Health.
- Keep source metrics locally for review.

Healther is local-first. It does not require an account, does not include analytics or advertising SDKs, and does not upload your health files. Your imports are processed on device, and Apple Health access is controlled by iOS permissions.

## Review Notes

Healther imports user-selected CSV and JSON health export files. The user chooses an import template or maps fields manually, previews the generated records, and then chooses whether to save compatible records to Apple Health.

HealthKit access is used only to write selected imported records and to validate compatible HealthKit types. Healther does not create an account, does not upload health files, and does not sync data to a backend.

Suggested review flow:

1. Launch the app.
2. Tap Add Import.
3. Choose a built-in template or Manual Import.
4. Select a CSV or JSON file.
5. Preview mapped records.
6. Request Health access and import only if desired.

If a test file is needed, use the synthetic samples in the repository under `Samples/`.
